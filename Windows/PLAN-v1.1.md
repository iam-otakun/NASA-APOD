# NASA APOD Windows 版新版功能清单（待 Fred 过目商量，2026-11-26 定规矩后首用）

现行 Windows 版 v1.0.5 的实况（Dash 已查源码确认）：
- 托盘菜单：标题项（点开定位当前归档文件）、刷新、打开官网、Settings / Check for Updates / About / Quit
- 有悬停预览窗（标题+日期+图）、气泡通知、设置（归档目录+登录自启）、自更新、双语
- 短板：抓图是旧解析；没有说明文字与署名；没有每日 .txt；视频日直接报错跳过（不存任何东西）

拟按 Mac 独立版 v1.0.0 同一架构补齐（版本号拟 v1.1.0）：

1. 新解析器：与 Mac 插件 1.9.3 同款 hero 图解析，删 og:image 兜底——根除存下站点模板假图的病
2. 说明窗：菜单加「查看说明…」，窗内大图 + 标题 + 日期 + 署名 + 说明全文，并可在本地归档里前后翻页（Mac 版详情窗的同款）
3. 每日 .txt：每天必存与照片同名的文本（标题、日期、署名、说明全文、来源链接），图片日视频日都存
4. 视频日：存 .mp4 本体（同名规则，上限 100 MB，超限只存文本与链接）；说明窗/预览里展示视频第一帧（实现走系统能力，细节编码时定）
5. 设为壁纸：菜单加一项，与 Mac 版对齐（现 Windows 版没有，只有定位文件）
6. 菜单缩略图（待定项）：Mac 版菜单顶部有缩略图，Windows 托盘菜单也能挂图——加不加请 Fred 定

Windows 版原有保留不动：悬停预览、气泡通知、设置与登录自启、自更新、双语、同一份 ~/.nasa-apod.conf 配置与归档目录（与 Mac 插件/独立版三方共用）。

发布照旧：GitHub 仓 NASA-APOD 发 Release，产物同步 Dash 文件夹；先在家里的 VM 上构建实测，再交付。
